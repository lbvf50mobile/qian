# Tool for learning Mandarin numbers

## About the Tool

In the idea the tool is used with a copy book. The question generated by the
tool and the answer are written by hand into the copy book.

- Start by `ruby qian.rb`. Or by `./qian.rb` if executive permitions enabled.  
- Exit by **Ctrl+D**.
- The tool logs into `log.txt` in the same dir were `qian.rb` exits. The log is
  used to manual increase the amount of sound files in the `sound` dir.
- The tool requires `mpv` - for playing sound files.
- Testing output `./qian.rb -t`.


## Test types

There are several test types:

- **generate** generate new number, show hanzi.
- **from_sound** like **generate**, but takes nume from `sound` dir.
- **from_sound_no_hanzi** like **from_sound**, but no hanzi, need listen and
  quess.
- **from_sound_num** get numer like `3143` and plays sound, need to guess `三千一百四十三`. 

## Numbers types

- **full** 3143 三千一百四十三 (sānqiān yībǎi sìshí sān)
- **twogap** 7005 七千零五 (qīqiān líng  wǔ)
- **baigap** 2043 二千零四十三 (èrqiān líng sìshí sān)
- **shigap** 3607 三千六百零七 (sānqiān liùbǎi líng qī)

## Mandarin numbers (Hanzi + PinYin)

- 0 零 (líng) 
- 1 一 (yī)
- 2 二 (èr)
- 3 三 (sān)
- 4 四 (sì)
- 5 五 (wǔ)
- 6 六 (liù)
- 7 七 (qī) 
- 8 八 (bā)
- 9 九 (jiǔ)
- 10 十 (shí)
- 100 百 (bǎi)
- 1000 千 (qiān)
