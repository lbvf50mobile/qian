# Tool for learning Mandaring numbers

- 0 零 (líng) 
- 1 一 (yī)
- 2 二 (èr)
- 3 三 (sān)
- 4 四 (sì)
- 5 五 (wǔ)
- 6 六 (liù)
- 7 七 (qī) 
- 8 八 (bā)
- 9 九 (jiǔ)
- 10 十 (shí)
- 100 百 (bǎi)
- 1000 千 (qiān)

- Exit by **Ctrl+D**.
- Testing output `./qian.rb -t`.

## Numbers types

- **full** 3143 三千一百四十三 sānqiān yībǎi sìshí sān  
- **twogap** 7005 七千零五 qīqiān líng  wǔ 
- **baigap** 2043 二千零四十三 èrqiān líng sìshí sān
