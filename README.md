# Tool for learning Mandarin numbers

## About the Tool

In the idea the tool is used with a copy book. The question generated by the
tool and the answer are written by hand into the copy book.

- Start by `ruby qian.rb`. Or by `./qian.rb` if executive permitions enabled.  
- Exit by **Ctrl+D**.
- The tool logs into `log.txt` in the same dir were `qian.rb` exits. The log is
  used to manual increase the amount of sound files in the `sound` dir.
- The tool requires `mpv` - for playing sound files.
- Testing output `./qian.rb -t`.
- `./qianlogfilter.rb sound log.txt > filterlog.txt; vim filterlog.txt` - get
  new numbers from the log to add as sound files.
- `./crqian.rb 10` a counter that ticks every `10` seconds and say Mandarin
  number of a count. Used as an auxiliary tool for [Hanzi Drill](https://github.com/lbvf50mobile/hanzidrill).


## Integratoin with  [Hanzi Drill](https://github.com/lbvf50mobile/hanzidrill)

The goal is to simplyphy Hanzi memorization. The `crian.rb` is used to repeat
a hanzi charackter again and again during writing it. Thus set of `aliases`
is used.

```Bash
export qianprefix=/home/dima/fun/qian/
export hanziprefix=/home/dima/fun/hanzidrill/

alias crqian="${qianprefix}crqian.rb"

alias lhanzi="crqian ${hanziprefix}docs/data/两liǎng.mp3 2 两" 
```
So learning a new hanzi charater is basicaly like changing the `lhanzi` alias.

```Bash
alias lhanzi="crqian ${hanziprefix}docs/data/两liǎng.mp3 2 两" 
```
## Test types

There are several test types:

- **generate** generate new number, show hanzi.
- **from_sound** like **generate**, but takes nume from `sound` dir.
- **from_sound_no_hanzi** like **from_sound**, but no hanzi, need listen and
  quess.
- **from_sound_num** get numer like `3143` and plays sound, need to guess `三千一百四十三`.
